A top-down heist game in one grand masquerade ballroom. Slip past four
patrolling guards with wide vision cones and three sweeping wall cameras,
hide inside the dancing crowd, pick the laser lock on the Crown of Aurelia,
and escape through the exit before the four-minute party ends.

## How to play

- **WASD / arrows** — move, or **click** anywhere to walk there
- **Q** — smoke bomb (×2): guards cannot see through it
- **E** — EMP (×2): freezes the wall cameras for 4 seconds
- **Hold F** at the pedestal — pick the laser lock, then grab the Crown
- **Crowd cover** — stand inside a dancing pair and guard cones sweep past you
- **Alarm** — CALM → SUSPICIOUS → HUNTED → LOCKDOWN; the whole ballroom's
  lighting shifts with the stage, and the tall gauge on the right wall shows it

## Run it

```sh
node serve.ts
# open http://localhost:8080 in desktop Chrome
```

Static files only — no build step, no network, sounds from WebAudio.
